Single-file React component (`AgentUseCases.jsx`) paired with a colocated stylesheet (`agent-use-cases.css`). The component owns its data in a local `LOOP_STEPS` array and composes three small presentational sub-components — `LoopIcon`, `LoopConnector`, and `LoopCard` — plus the default-exported `AgentUseCases` section. Entry is a `<section>` with id `agent-use-cases` and `data-reveal="panel"`, which the parent page's reveal system consumes; each card uses an `IntersectionObserver` to toggle an `.is-inview` class for scroll-triggered entrance animations, while CSS custom properties `--auc-i` and `--step-i` drive per-card/per-step stagger delays. Styling lives entirely in the sibling CSS file using BEM-style `auc-*` classes scoped under `.auc-section`, with responsive breakpoints at 900px and 480px and a `prefers-reduced-motion` override.
