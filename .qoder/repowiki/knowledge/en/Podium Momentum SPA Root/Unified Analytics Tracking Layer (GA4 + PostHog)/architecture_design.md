Flat module (`src/analytics.js`) exposing a small public API: `initAnalytics`, `trackPageView`, `trackEvent`, plus domain-specific helpers (`trackContactSubmit`, `trackNewsletterSubscribe`, `trackCtaClick`, `trackVoiceCallStart/End`, `trackServiceView`, `trackIndustryView`). Internally it is a thin shim over two independent backends — the `posthog-js` SDK (imported) and GA4's global `gtag`/`dataLayer` (injected dynamically via a `<script>` tag). A module-level `initialized` flag ensures single initialization, and each backend is gated by its own environment variable (`VITE_GA4_MEASUREMENT_ID`, `VITE_POSTHOG_KEY`, `VITE_POSTHOG_HOST`) plus a `'XXXX'` placeholder check so local dev stays silent. Dependency direction is outward-only: this module depends on `posthog-js` and browser globals (`window`, `document`); callers depend only on the exported functions.
