Single-file Vercel Edge/Serverless handler exporting a default `handler(req, res)` function. It instantiates the `@blandsdk/client` with an admin client configured from the `BLAND_API_KEY` environment variable and calls `admin.agents.authorize({ agentId })` to obtain a short-lived token. The file is self-contained: CORS preflight handling, method gating (POST only), request body validation (`agentId` required), env guard, and error mapping (400 / 405 / 500 / 502) are all in one function — no internal sub-packages or shared helpers.
