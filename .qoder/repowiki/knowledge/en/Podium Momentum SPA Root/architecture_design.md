This scope owns only project scaffolding — no React source lives here. `index.html` is the SPA entry point (mounts `<div id="root">`, sets `data-theme` before JS runs) and `vite.config.js` registers `@vitejs/plugin-react` plus a custom `bland-api-dev` plugin that mounts Express-style middleware at `/api/agent-authorize` to mint Bland webchat tokens during `pnpm dev`. The same endpoint is implemented as a separate serverless function in the `api/` child module for production; both call the Bland Admin SDK with `BLAND_API_KEY` kept server-side. `vercel.json` rewrites every non-`/assets/*` and non-`/api/*` route to `index.html` so client-side routing works on Vercel while preserving the API routes. `pnpm-workspace.yaml` marks this directory as a pnpm workspace root even though only one package exists. Static marketing screenshots sit at the repository root and are referenced by absolute paths rather than imported through Vite's asset pipeline.
