Single-file React component (`MCP2099.jsx`) plus its stylesheet (`mcp2099.css`). The page is composed of stateless section components (`HeroSection`, `NeuralSection`, `ProtocolSection`, `LogsSection`, `DashboardSection`) orchestrated by the default-exported `MCP2099` root, which owns only global state: loader completion, dark/light theme toggle, and active nav section (tracked via an `IntersectionObserver`). Three independent `<Canvas>` scenes are embedded — `HeroScene` (globe + starfield), `NeuralScene` (neural core + particles) — built with `@react-three/fiber`/`@react-three/drei` and custom GLSL vertex/fragment shaders declared as template literals at the top of the file. A `CinematicLoader` drives a fixed overlay with a hand-drawn canvas ring animation and a scrambled-text decode effect before revealing the page. Navigation is client-side smooth-scroll to `id` anchors; no router is used internally. CSS uses a `--mcp-*` CSS-variable token system scoped under `.mcp2099`, with a `.light-mode` modifier overriding tokens for light theme. External dependencies are purely visual: `three`, `@react-three/*`, `gsap` (for staggered section entrance animations), and `lucide-react` icons.
