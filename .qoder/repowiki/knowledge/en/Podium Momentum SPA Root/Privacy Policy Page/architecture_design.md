Single-file presentational component (`src/PrivacyPolicy.jsx`) exporting a default function that maps over a local `sections` array to render `<section>` blocks; content is pure data (title, body, list) with no props, state, or side effects. Styling lives in a sibling stylesheet (`src/privacy-policy.css`) scoped under the `pp-*` class namespace. The component has no internal sub-packages or external dependencies beyond React and its own CSS file, making it a leaf view consumed by the app's router.
