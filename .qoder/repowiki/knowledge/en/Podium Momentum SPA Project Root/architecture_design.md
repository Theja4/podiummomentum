This scope is the project root only — no source code lives here. The SPA entry point is `index.html`, which declares `<div id="root">` and loads `/src/main.jsx`. `vite.config.js` wires up `@vitejs/plugin-react`, sets `appType: 'spa'`, and ignores `qa-*.html` files in dev so Visual-QA helpers can write temporary HTML without triggering full reloads. `vercel.json` rewrites every non-`/assets/*` route to `index.html` for client-side routing at deploy time. `pnpm-workspace.yaml` exists as a workspace root marker (with an `allowBuilds.esbuild` placeholder) even though only one package is present. Runtime marketing screenshots (`handoff-portrait.png`, `selected-work-*`, `solution-*-desktop.png`, etc.) sit at the repository root and are referenced by absolute paths rather than imported through the Vite asset pipeline.
